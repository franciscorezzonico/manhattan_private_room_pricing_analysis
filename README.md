# Manhattan Private-Room Pricing Analysis

An exploratory and multiple linear regression analysis of factors associated with nightly prices for private-room rental listings in selected Manhattan neighborhoods: Midtown, West Village, Nolita, SoHo, and the Upper East Side.

## Overview

This project examines whether service fees, review volume, cancellation policy, and minimum-night requirements are associated with the nightly price of private-room rental listings in Manhattan, New York City.

The workflow imports the NYC property-rental data, applies documented missing-value rules, restricts the sample to the project population, treats unusually high minimum-stay requirements using Tukey’s $1.5 \times IQR$ rule, saves a clean analytical dataset, and estimates a multiple linear regression model.

The analysis is descriptive and observational. Regression coefficients represent associations within the selected sample and should not be interpreted as causal effects.

## Research question

How are service fees, number of reviews, cancellation policy, and minimum-night requirements associated with nightly private-room prices in selected Manhattan tourist neighborhoods?

## Methods

- **Population:** Private-room rental listings in Midtown, West Village, Nolita, SoHo, and the Upper East Side in Manhattan, NYC
- **Outcome:** Nightly listing price in U.S. dollars
- **Predictors:** Service fee, number of reviews, cancellation policy, and minimum nights required
- **Model:** Multiple linear regression
- **Cancellation-policy reference group:** Flexible
- **Outlier treatment:** Listings above the upper Tukey fence for `MINIMUM_NIGHTS` are excluded
- **Diagnostics:** Standard residual plots, a heteroscedasticity test, variance inflation factors, and a supplementary Durbin–Watson test
- **Effect size and power:** Cohen’s $f^2$ and post hoc regression power

## Key findings

The original model results indicate a strong positive association between service fee and nightly price. The estimated coefficient for service fee is approximately 4.95, meaning that a one-dollar increase in service fee is associated with an estimated 4.95-dollar increase in nightly price, holding the other modeled variables constant.

Number of reviews, cancellation policy, and minimum-night requirements were not statistically significant predictors in the reported model. The model diagnostics indicate that important ordinary least squares assumptions, including homoscedasticity and the absence of influential observations, should be evaluated carefully when interpreting the findings.

## Reproducing the analysis

### Prerequisites

- R 4.3 or later
- Quarto
- RStudio, Positron, or another editor capable of rendering Quarto documents

### Required R packages

Install the required packages once in R:

```r
install.packages(c(
  "readxl",
  "dplyr",
  "tidyr",
  "stringr",
  "tibble",
  "stargazer",
  "ggplot2",
  "plotly",
  "htmlwidgets",
  "lmtest",
  "car",
  "pwr"
))
```

### Render the Quarto report

1. Clone or download this repository.
2. Confirm that the original dataset is available in `data/` using the filename referenced in the Quarto document.
3. Open `notebooks/manhattan-private-room-pricing-analysis.qmd` in your preferred Quarto-compatible editor.
4. Render the document.

You can also render from a terminal opened in the repository root:

```bash
quarto render notebooks/manhattan-private-room-pricing-analysis.qmd
```

The workflow saves the processed analytical sample as:

```text
data/manhattan_private_room_listings_clean.csv
```

and places rendered outputs in the `outputs/` directory when the project configuration is set accordingly.

## Limitations

- The analysis is restricted to private rooms in five selected Manhattan neighborhoods and may not generalize to other boroughs, neighborhood types, or listing types.
- The model uses observational listing data; estimated relationships are associations, not causal effects.
- Service fee may be mechanically related to nightly price if fees are calculated as a percentage of booking value, which can inflate the apparent explanatory power of the model.
- Diagnostic findings should be considered before drawing strong inferential conclusions from conventional ordinary least squares standard errors.
